# 本地文件去重工具 — 设计文档

**日期**: 2026-07-07
**状态**: 待实现

## 概述

基于内容（SHA-256）的本地文件去重桌面工具，JavaFX GUI，用于整理重复的图片和视频文件。

## 核心逻辑

- 去重方式：SHA-256 哈希，字节级精确匹配
- 扫描目录递归遍历，按文件名（不含路径）字母序排序后依次哈希
- 文件名排序第一的文件保留原位，后续哈希相同的文件移入输出目录
- 移动目标：`输出目录/重复自_<保留文件名>/`
- 跳过符号链接，跳过无法访问的文件

## 运行方式

```bash
mvn javafx:run -pl ddf-common-script
```

或 IDE 中直接运行 `DedupApplication.main()`。

## 错误处理

- 无权访问的文件/目录 → 跳过，记录日志
- 目标目录同名文件夹 → 自动加 `_1`、`_2` 后缀
- 移动失败（权限/占用）→ 跳过，UI 标记红色
- 未预期异常 → 错误对话框，不崩溃
