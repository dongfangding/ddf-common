# 视频目录检测 — 设计文档

## 概述

在现有"文件工具箱"JavaFX 应用中新增**视频目录检测**面板。用户指定一个目录，程序扫描其直接子目录，标记哪些子目录树下包含视频文件。结果仅在当前会话有效，可点击打开资源管理器。

## 核心逻辑

### 扫描规则

- 用户指定目录后，列出其**直接子目录**作为扫描单元
- 对每个子目录独立使用 `Files.walkFileTree` 遍历
- 遇到第一个匹配视频扩展名的文件 → 标记该子目录，**终止当前子树遍历**，进入下一个子目录
- 这意味着每个子目录至多被扫描到"发现第一个视频"即停止

### 视频扩展名（内置固定）

`mp4, mkv, avi, mov, wmv, flv, webm, m4v, ts, rmvb, 3gp`

### 避免重复

由于采用"逐个子目录独立扫描 + 首次命中即终止"策略，天然避免重复：
- 不同子目录互不干扰
- 同一子树内不会做多余扫描

## UI 设计

作为 `DedupApplication` 的第 5 个功能面板，加入左侧导航。

```
┌──────────────────────────────────────────────┐
│  视频目录检测                                  │
│  扫描目录: [____________] [浏览...] [开始扫描]   │
│  进度: [=========>           ] 3/10           │
│                                              │
│  ┌─ 含视频的目录 ──────────────────────────┐  │
│  │  D:\Videos              [打开目录]       │  │
│  │  D:\Backup\Movies       [打开目录]       │  │
│  │  D:\Downloads           [打开目录]       │  │
│  └────────────────────────────────────────┘  │
```

## 数据流

1. 用户选择目录 → 列出直接子目录
2. 后台线程逐个扫描子目录 → 实时更新进度条和状态文本
3. 含视频的子目录加入结果列表（`ListView`）
4. 点击"打开目录"→ `Desktop.getDesktop().open(dir)` 调用系统资源管理器
5. 关闭程序后结果不保留（无持久化）

## 代码结构

### 新增文件

- `ddf-common-script/src/main/java/com/ddf/boot/common/script/file/dedup/ui/VideoDetectPanel.java`
  - 继承 `VBox`，遵循现有 Panel 模式
  - 包含扫描逻辑，不单独抽取 Service

### 修改文件

- `DedupApplication.java` — 注册新面板，追加到 `FUNCTION_NAMES` 和 `panels` map

## 注意事项

- 扩展名匹配忽略大小写
- 空目录或无子目录时给出提示
- 扫描在后台线程执行，UI 通过 `Platform.runLater` 更新
- 按钮在扫描期间禁用，防止重复触发
